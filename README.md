# FreeCash landing page

A 1:1 rebuild of the FreeCash reward page, with no tracking pixels or outbound links.

## Files
- `index.html` has the page markup
- `styles.css` has all the styling
- `images/freecash-capa2.png` is the banner image

## Preview
Open `index.html` in a browser, or run `npx serve .` in this folder.

## Add your link
The START EARNING NOW button (`id="cta"`) points to `#`. Put your own URL in its `href`.
